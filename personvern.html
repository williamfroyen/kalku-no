Personvern

Innledning

Kalku tar personvern på alvor. Nettsiden er utformet slik at den kan brukes uten at Kalku aktivt samler inn personopplysninger om deg.

Behandlingsansvarlig for behandling av personopplysninger som Kalku selv er ansvarlig for, er:

  • Navn: William Frøyen
  • E-post: kontakt@kalku.no

1. Personopplysninger ved bruk av nettsiden

Kalku samler ikke inn, lagrer eller analyserer personopplysninger som navn, e-postadresse eller andre kontaktopplysninger når du bruker nettsidens kalkulatorer og øvrige funksjoner.

Opplysninger du skriver inn i kalkulatorene behandles lokalt i nettleseren og sendes ikke til Kalku.

2. Informasjonskapsler og sporing

Nettsiden bruker ikke analyseverktøy, sporingsverktøy eller andre teknologier for å følge besøkende på tvers av sider eller tjenester.

Kalku bruker ikke informasjonskapsler (cookies) til annonsering, analyse, profilering eller markedsføring.

3. Drift av nettsiden og tekniske opplysninger

Nettsiden hostes via GitHub Pages. Når du besøker nettsiden, kan GitHub behandle tekniske opplysninger som er nødvendige for å levere og sikre tjenesten. GitHub opplyser blant annet at IP-adressen til besøkende på GitHub Pages logges og lagres av sikkerhetshensyn.

Kalku bruker ikke slike tekniske opplysninger til analyse, profilering, annonsering, markedsføring eller sporing av besøkende.

Mer informasjon om hvordan GitHub behandler personopplysninger finnes i GitHub General Privacy Statement .

4. Kontakt via e-post

Dersom du kontakter Kalku via e-post, vil vi behandle opplysningene du selv oppgir, for eksempel e-postadresse, navn og innholdet i meldingen.

Opplysningene brukes kun for å besvare og følge opp henvendelsen. Behandlingsgrunnlaget er normalt vår berettigede interesse i å kunne kommunisere med personer som kontakter oss, jf. personvernforordningen artikkel 6 nr. 1 bokstav f.

E-post og tilhørende personopplysninger oppbevares ikke lenger enn det som er nødvendig for å behandle og følge opp henvendelsen, med mindre videre oppbevaring er nødvendig for å oppfylle en rettslig forpliktelse eller ivareta et rettskrav.

5. Deling med tredjeparter

Kalku selger ikke personopplysninger og deler ikke personopplysninger med tredjeparter for markedsføring, annonsering, profilering eller analyse.

Tekniske opplysninger kan behandles av GitHub i forbindelse med hosting, levering og sikkerhet for nettsiden, som beskrevet ovenfor.

6. Dine rettigheter

Dersom Kalku behandler personopplysninger om deg, kan du etter personvernregelverket, avhengig av behandlingen og omstendighetene, blant annet ha rett til informasjon, innsyn, retting, sletting, begrensning av behandling og til å protestere mot behandlingen.

Du kan kontakte oss på kontakt@kalku.no dersom du ønsker å utøve dine rettigheter eller har spørsmål om hvordan personopplysninger behandles.

Du har også rett til å klage til Datatilsynet dersom du mener at behandlingen av personopplysninger er i strid med personvernregelverket. Mer informasjon finnes på Datatilsynets nettsider.

7. Informasjonssikkerhet

Kalku benytter passende tekniske og organisatoriske tiltak for å beskytte personopplysninger som vi behandler mot uautorisert tilgang, endring, tap eller annen ulovlig behandling.

8. Endringer i personvernerklæringen

Denne personvernerklæringen kan bli oppdatert dersom nettsidens funksjoner eller behandling av personopplysninger endres. Den nyeste versjonen vil alltid være tilgjengelig på denne siden.
